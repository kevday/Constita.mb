Aparência e temas →

Arraste fotos ou vídeos curtos para a categoria. Eles são salvos em img/<categoria>/ e enviados ao GitHub em um único commit.

1. Conexão com o GitHub

Crie em GitHub → Settings → Developer settings → Fine-grained tokens, só neste repositório, com Contents: Read and write. Fica salvo apenas neste navegador.

2. Adicionar peças

Solte fotos sobre a categoria (ou clique nela para escolher os arquivos). Depois de criada, cada peça aceita mais fotos pelo quadro “+ foto”.

3. Peças publicadas

Edite nome, preço e estoque, adicione ou remova fotos (clique numa foto para torná-la a capa) e desative ou remova peças. Estoque 0 mostra “Esgotado”.

Conecte ao GitHub para carregar.

Configuração do site

Edita o arquivo data/site.json: textos, WhatsApp, Instagram e marcas. Clique em Publicar para enviar.

Conecte ao GitHub para carregar.
